# Security Policy

## Supported releases

Security updates are provided for the latest published Aethmere CLI release.

| Version | Supported |
|---|---|
| 0.5.x | Yes |
| Earlier versions | Upgrade required |

## Report a vulnerability

Please use this repository's private vulnerability reporting or GitHub Security
Advisories when available. If the report cannot be submitted privately, contact
the project through the support channel at [aethmere.com](https://aethmere.com)
and ask for a private security-reporting route.

Do not open a public issue containing:

- passwords, API keys, tokens, or connection codes;
- private memories or personal information;
- exploit details for an unpatched vulnerability;
- confidential customer or project data.

Include the affected version, operating system, reproduction steps, impact, and
the minimum evidence needed to verify the issue. Please avoid accessing data that
does not belong to you.

## Download integrity

Only install releases from this repository or
[aethmere.com](https://aethmere.com). Verify the published SHA-256 value. The
Aethmere updater additionally verifies signed metadata, package size, and
SHA-256 before installation.
