# Aethmere CLI 0.5.0

This is the first Aethmere CLI release distributed through the public Aethmere
GitHub repository.

## Highlights

- One user-level connection for supported AI clients.
- No need to reconnect when switching project folders.
- Optional account login and cloud synchronization remain separate from local
  client connection.
- Desktop upload remains disabled until explicitly enabled by the user.
- Signed update checks, explicit update confirmation, and rollback support.
- Package diagnostics through `aethmere doctor --profile package`.

## Install

Requires Node.js 18 or newer.

```bash
npm install -g https://github.com/kzkz137806/aethmere-os/releases/download/v0.5.0/aethmere-cli-0.5.0.tgz
aethmere --version
aethmere connect
aethmere doctor --profile package
```
