# Aethmere CLI 0.7.0

This is the first Aethmere CLI release distributed through the public Aethmere
GitHub repository.

## Highlights

- Status overview, session handoff, task convergence, and multi-session
  coordination commands.
- User-managed private skill lifecycle, team roles, and allowlisted automation
  with explicit approval.
- Task-scoped remote access to shared skills and knowledge. The client does not
  download or cache shared capability source.
- Account-level cloud memory, personal document knowledge, trusted search,
  explicit upload controls, and signed rollback-capable updates.

## Install

Requires Node.js 22 LTS (`>=22.13.0 <23`).

```bash
npm install -g https://github.com/kzkz137806/aethmere-os/releases/download/v0.7.0/aethmere-cli-0.7.0.tgz
aethmere --version
aethmere connect
aethmere doctor --profile package
```
