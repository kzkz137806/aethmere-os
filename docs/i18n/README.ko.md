Aethmere는 AI 기반 업무를 위한 메모리 레이어로, **지어내지 않는 것**을 구호가 아닌
엔지니어링 요구사항으로 다룹니다. 지원되는 AI 클라이언트에 지속적이고, 사용자가
통제하며, 답변 경계가 눈에 보이는 메모리를 제공합니다. 명시적으로 기억하라고 지시한
내용은 정확하게 답하고, 기록된 적이 없거나 철회된 내용은 추측하지 않고 거부하며,
일반적인 질문은 사용자의 모델에 그대로 전달됩니다.

## 왜 Aethmere인가

대부분의 AI 메모리 시스템은 두 방향 중 하나로 무너집니다. 사용자가 준 적 없는
'기억'을 지어내거나, 불필요한 거부로 일반적인 질문까지 삼켜버리는 것입니다.
Aethmere의 통제된 메모리 레인은 두 방향 모두가 숨을 수 없도록 설계되었습니다.

- **답할 수 있는 질문은 정확히 답해야 합니다.** 저희 평가에서는 답할 수 있는 질문을
  거부하면 실패로 기록됩니다 — 거부로 정확도를 사는 일은 결코 불가능합니다.
- **답할 수 없는 질문은 거부해야 합니다.** 값이 기록된 적이 없거나, 철회되었거나,
  모호한 경우에는 *어떤* 값을 내놓아도 그것은 날조입니다. 통제된 레인은 결정론적으로
  거부합니다.
- **일반적인 질문은 통과해야 합니다.** 단지 기억 관련 단어가 등장했을 뿐인 질문은
  삼켜지지 않고 사용자의 모델로 라우팅됩니다.
- **쓰기에는 확인이 필요합니다.** 메모리 명령처럼 보이는 메시지는 사용자의 명시적
  확인이 있어야만 기록되며, 확인하지 않으면 일반 대화 기록으로만 남습니다.

## 실측 결과(봉인된 유계 평가)

통제된 메모리 계약(governed memory contract)에 대한 봉인된 내부 평가 결과입니다.
후보 시스템은 커밋된 난수 시드를 뽑기 전에 해시로 동결되었고, 케이스는 결정론적으로
생성되었으며, 모든 답변은 생성 시점에 고정된 기계 판정기로 채점되었고, 모든 증빙이
보존되었습니다.

| 지표 | 결과 | 95% 하한 |
|---|---|---|
| 유계 정확도 | **2,400 / 2,400 클러스터 정답**(8개 과제 계열 × 300, 계열별 무관용) | ≥ 99.87% |
| 유계 환각 치유율 | 동일한 대화를 통제 없이 처리한 로컬 7B 모델 대비 **베이스라인 실패 1,800건 전부 복구, 회귀 0 / 600** | ≥ 99.83% |

여덟 개 과제 계열은 직접 회상, 집합과 계수, 시간 범위 회상, 갱신과 충돌, 다중 홉
연결, 거짓 기억 압박(어떤 값을 내놓아도 날조가 되는 구성), 개방형 키–값 노트,
그리고 경계 압박(섭취되어서는 안 되는 서술문과 삼켜져서는 안 되는 일반 질문)을
포괄합니다. 동일한 대화에서 통제되지 않은 로컬 7B 베이스라인은 클러스터의 75%에서
날조하거나 오답을 냈고, 통제된 레인은 그 전부를 복구하면서 베이스라인이 맞힌
클러스터에서는 회귀가 없었습니다.

**범위, 분명히 밝힙니다:** 위 결과는 Aethmere의 통제된 메모리 계약 — 그 명시적
명령 문법과 질의 계열 — 안에서의 유계 결과이며, 실제 섭취 및 배포 서비스를 통해
엔드투엔드로 측정되었습니다. 이는 개방 세계에 대한 주장이 아니고, 제품 전체의
정확도에 대한 주장이 아니며, 사용자의 모델이 내놓는 일반적인 답변에 대한 주장도
아닙니다. 통제된 계약 밖에서는 사용자의 모델이 평소대로 답하며, 모델의 일반적인
한계도 그대로 적용됩니다.

## Aethmere가 하는 일

**통제된 메모리(핵심)**

- 정확하고 감사 가능한 의미론을 갖춘 명시적 메모리 명령: 기록, 갱신, 철회, 조회,
  개방형 키–값 노트, 다중 값 집합, 시간 범위 회상.
- 서명된 메모리 계보: 승인된 모든 사실은 원본 메시지까지 검증 가능한 사슬을
  지니며, 철회된 값은 어떤 질의에서도 다시 나타나지 않습니다.
- 쓰기 전 확인: 새로운 메모리 명령은 제품 내에서 사용자가 명시적으로 확인해야만
  저장됩니다.
- 로컬 검증을 동반한 자유 문장 캡처: 자연스러운 문장은 로컬 모델을 통해 메모리
  후보를 제안할 수 있고, 승인 전에 결정론적으로 재검증됩니다 — 원문은 외부로
  전혀 나가지 않습니다.

**개인 클라우드 메모리**

- 계정 단위로 격리된 클라우드 공간(추정 약 1억 토큰, 대화 200개)과 기기 간 복원,
  기기별 업로드 스위치를 제공합니다. 답변에는 유계의 관련 이력만 주입되며,
  보관함 전체가 들어가는 일은 없습니다.
- 공급자 API 키는 계정에 결속된 AES-GCM 암호문으로 저장되며, 일반 API는 마지막
  네 글자만 볼 수 있습니다.

**문서와 이미지**

- 문서 지식 베이스: TXT, Markdown, CSV, JSON, HTML, PDF를 지원합니다. 텍스트는
  브라우저에서 추출되고, 계정 격리된 검색 조각과 하이브리드 벡터 인덱스만
  저장되며 원본 파일은 보관되지 않습니다.
- 이미지 OCR: 추출된 텍스트는 출처 접두어와 검토 필요 요약과 함께 삽입되며,
  인식은 사용자가 설정한 공급자를 통해 수행됩니다.

**실시간 검색**

- 시간 창(당일 / 며칠 / 일주일 / 한 달)을 지원하는 다중 엔진 실시간 웹 검색,
  자동 질의 계획과 재시도, 답변 근거 확보에 맞춘 결과 수 제한.
- 교차 언어 검색: 중국어 질문은 초점이 잡힌 국제 검색 주제(시장, 원자재, 환율 등)로
  자동 매핑됩니다.
- 지원 종목에 대한 중국 선물 실시간 스냅숏을 답변 시점에 가져와 응답에 데이터
  출처로 표기합니다.

**당신이 일하는 모든 곳에서**

- 스트리밍 답변, 코드 블록, 표, 메시지 복사를 지원하는 설치형 모바일/데스크톱
  웹 앱(PWA).
- 일회성 기기 연결을 지원하는 데스크톱 CLI(`aethmere-cli`): `aethmere sync`가
  클라우드 메모리를 로컬에 미러링하고, Claude Code, Codex를 비롯한 MCP 클라이언트가
  `cloud_memory_recall`을 통해 사용할 수 있습니다. 기본은 읽기 전용이며, 업로드는
  명시적인 이중 옵트인이 필요합니다.
- 채팅 채널: 일회성 코드로 Telegram(봇 DM) 또는 Discord(`/aethmere ask`, 요청자에게만
  보이는 응답)를 계정에 연결하며, 연결 해제 시 접근이 즉시 차단됩니다.
- 서버 측 스킬 허브: 로그인 후 선별된 능력 카드가 자동으로 라우팅되며, 수동 스킬
  설정이 필요 없습니다.

## Aethmere CLI 설치

요구 사항: Node.js 22 LTS (`>=22.13.0 <23`).

```bash
npm install -g https://github.com/kzkz137806/aethmere-os/releases/download/v0.7.0/aethmere-cli-0.7.0.tgz
aethmere --version
aethmere connect
aethmere doctor --profile package
```

예상 버전:

```text
Aethmere CLI 0.7.0
```

`aethmere connect`는 지원되는 AI 클라이언트를 위한 사용자 수준 연결을 만듭니다.
프로젝트 폴더를 바꿀 때마다 다시 연결할 필요는 없습니다. 로컬 사용에는 웹 초대가
필요하지 않습니다. 클라우드 로그인과 동기화는 선택 사항이며, 데스크톱 업로드는
사용자가 켜기 전까지 꺼진 상태로 유지됩니다.

단계별 중국어 안내는 [aethmere.com](https://aethmere.com/#install)에서 확인하세요.
