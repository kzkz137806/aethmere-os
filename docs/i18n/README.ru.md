Aethmere — это слой памяти для работы с ИИ, в котором «**не выдумывать**» является
инженерным требованием, а не лозунгом. Он даёт поддерживаемым ИИ-клиентам долговременную,
подконтрольную пользователю память с видимыми границами ответа: то, что вы явно попросили
запомнить, воспроизводится точно; то, что никогда не записывалось или было отозвано,
получает отказ вместо догадки; обычные вопросы передаются вашей модели без изменений.

## Почему Aethmere

Большинство систем ИИ-памяти проваливаются в одну из двух сторон: они выдумывают
воспоминания, которых вы им не давали, либо проглатывают обычные вопросы ненужными
отказами. Управляемая полоса памяти Aethmere устроена так, что ни одна из этих
сторон не может остаться незамеченной:

- **На отвечаемые вопросы нужно отвечать точно.** Отказ на отвечаемый вопрос
  засчитывается в нашей оценке как провал — точность нельзя купить отказами.
- **На неотвечаемые вопросы нужно отвечать отказом.** Если значение никогда не
  записывалось, было отозвано или неоднозначно, выдача *любого* значения была бы
  выдумкой. Управляемая полоса отказывает детерминированно.
- **Обычные вопросы должны проходить насквозь.** Вопрос, который лишь упоминает
  слова о памяти, направляется вашей модели, а не проглатывается.
- **Записи подтверждаются.** Сообщение, похожее на команду памяти, записывается
  только после вашего явного подтверждения; отказ оставляет его обычной историей чата.

В запечатанной внутренней оценке управляемого контракта памяти — кандидат заморожен

Восемь семейств задач охватывают прямое припоминание, множества и подсчёт,
припоминание с привязкой ко времени, обновления и конфликты, многошаговые связи,

## Что делает Aethmere

**Управляемая память (ядро)**

- Явные команды памяти с точной, проверяемой семантикой: записать, обновить, отозвать,
  найти, а также открытые заметки «ключ — значение»; множества с несколькими
  значениями; припоминание с привязкой ко времени.
- Подписанная родословная памяти: каждый принятый факт несёт проверяемую цепочку
  до исходного сообщения; отозванные значения больше никогда не всплывают ни в одном запросе.
- Подтверждение перед записью: новые команды памяти требуют вашего явного
  подтверждения в продукте, прежде чем что-либо будет сохранено.
- Свободный ввод с локальной проверкой: естественные предложения могут предлагать
  кандидатов в память через локальную модель и детерминированно перепроверяются
  перед принятием — с нулевой отправкой вашего исходного текста наружу.

**Личная облачная память**

- Изолированное по учётной записи облачное пространство (около 100 млн оценочных
  токенов, 200 диалогов) с восстановлением между устройствами; переключатели выгрузки
  для каждого устройства; в ответы подставляется только ограниченная релевантная
  история — никогда не весь архив.
- API-ключи провайдеров хранятся в виде шифротекста AES-GCM, привязанного к вашей
  учётной записи; обычные API видят только последние четыре символа.

**Документы и изображения**

- База знаний документов: TXT, Markdown, CSV, JSON, HTML и PDF; текст извлекается
  в вашем браузере, и сохраняются только изолированные по учётной записи фрагменты
  для поиска и гибридный векторный индекс — исходные файлы не хранятся.
- OCR изображений: извлечённый текст вставляется с префиксом источника и пометкой
  о необходимости проверки; распознавание выполняется через настроенного вами провайдера.

**Поиск в реальном времени**

- Многодвижковый веб-поиск в реальном времени с окнами свежести (день / несколько
  дней / неделя / месяц), автоматическим планированием запросов и повторами, а также
  ограничением числа результатов, настроенным под обоснование ответа.
- Межъязыковой поиск: вопросы на китайском автоматически преобразуются в
  сфокусированные международные поисковые темы (рынки, сырьевые товары, валюты и другое).
- Актуальные снимки китайского фьючерсного рынка по поддерживаемым инструментам,
  запрашиваемые в момент ответа и указываемые в ответе как источники данных.

**Везде, где вы работаете**

- Устанавливаемое мобильное/десктопное веб-приложение (PWA) с потоковыми ответами,
  блоками кода, таблицами и копированием сообщений.
- Десктопный CLI (`aethmere-cli`) с одноразовой привязкой устройства: `aethmere sync`
  зеркалирует вашу облачную память локально; Claude Code, Codex и другие MCP-клиенты
  могут использовать её через `cloud_memory_recall`. По умолчанию только чтение;
  выгрузка требует явного двойного согласия.
- Каналы чата: привяжите Telegram (личные сообщения боту) или Discord
  (`/aethmere ask`, эфемерные ответы) к своей учётной записи одноразовыми кодами;
  отвязка немедленно закрывает доступ.
- Серверный хаб навыков: отобранные карточки возможностей маршрутизируются
  автоматически после входа — ручная настройка навыков не нужна.

## Установка Aethmere CLI

Требования: Node.js 22 LTS (`>=22.13.0 <23`).

```bash
npm install -g https://github.com/kzkz137806/aethmere-os/releases/download/v0.7.0/aethmere-cli-0.7.0.tgz
aethmere --version
aethmere connect
aethmere doctor --profile package
```

Ожидаемая версия:

```text
Aethmere CLI 0.7.0
```

`aethmere connect` создаёт подключение на уровне пользователя для поддерживаемых
ИИ-клиентов. Переподключаться при смене папки проекта не нужно. Локальное
использование не требует веб-приглашения. Вход в облако и синхронизация
необязательны, а выгрузка с десктопа остаётся выключенной, пока пользователь её не включит.

Пошаговое руководство на китайском языке доступно на
[aethmere.com](https://aethmere.com/#install).

## Модель продукта

Aethmere использует модель «публичный клиент / приватное ядро»:

- публичные точки входа для дистрибуции и интеграции;
- проприетарные размещённые основные сервисы;
- загружаемый клиент для пользователей;
- отсутствие публичного раскрытия исходного кода ядра.

Содержимое этого репозитория и его релизных артефактов является проприетарным, если
в файле явно не указано иное. Никакая лицензия с открытым исходным кодом не
предоставляется. См. [NOTICE.md](NOTICE.md).
