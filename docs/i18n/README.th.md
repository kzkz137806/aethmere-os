Aethmere คือชั้นความจำ (memory layer) สำหรับการทำงานที่มี AI ช่วย ซึ่งถือว่า
**การไม่กุขึ้นมาเอง** เป็นข้อกำหนดทางวิศวกรรม ไม่ใช่แค่คำโฆษณา มันมอบความจำที่คงทน
ผู้ใช้ควบคุมได้ และมีขอบเขตคำตอบที่มองเห็นได้ ให้กับไคลเอนต์ AI ที่รองรับ กล่าวคือ
สิ่งที่คุณสั่งให้จำไว้อย่างชัดเจนจะถูกตอบอย่างแม่นยำ สิ่งที่ไม่เคยถูกบันทึกหรือถูกเพิกถอนไปแล้ว
จะถูกปฏิเสธแทนการเดา ส่วนคำถามทั่วไปจะถูกส่งผ่านไปยังโมเดลของคุณโดยไม่ถูกแตะต้อง

## ทำไมต้อง Aethmere

ระบบความจำ AI ส่วนใหญ่มักล้มเหลวไปในทางใดทางหนึ่งจากสองทางนี้ คือหลอนสร้างความจำที่คุณ
ไม่เคยให้ไว้ หรือกลืนคำถามธรรมดาไปด้วยการปฏิเสธที่ไม่จำเป็น เลนความจำแบบมีการกำกับ
(governed memory lane) ของ Aethmere ถูกสร้างขึ้นเพื่อไม่ให้ทั้งสองทางนั้นหลบซ่อนได้:

- **คำถามที่ตอบได้ต้องถูกตอบอย่างแม่นยำ** การปฏิเสธคำถามที่ตอบได้นับเป็นความล้มเหลว
  ในการประเมินของเรา — ความแม่นยำไม่มีวันซื้อได้ด้วยการปฏิเสธ
- **คำถามที่ตอบไม่ได้ต้องถูกปฏิเสธ** หากค่าใดไม่เคยถูกบันทึก ถูกเพิกถอนไปแล้ว หรือกำกวม
  การปล่อยค่า *ใด ๆ* ออกมาย่อมเป็นการกุขึ้น เลนที่มีการกำกับจะปฏิเสธอย่างเป็นระบบแน่นอน
- **คำถามธรรมดาต้องถูกส่งผ่าน** คำถามที่เพียงเอ่ยถึงคำเกี่ยวกับความจำจะถูกกำหนดเส้นทาง
  ไปยังโมเดลของคุณ ไม่ถูกกลืนไป
- **การเขียนต้องได้รับการยืนยัน** ข้อความที่ดูเหมือนคำสั่งความจำจะถูกบันทึกก็ต่อเมื่อคุณ
  ยืนยันอย่างชัดเจนเท่านั้น หากปฏิเสธ ข้อความนั้นจะคงอยู่เป็นเพียงประวัติแชตธรรมดา

## ผลการวัดจริง (การประเมินแบบผนึกและมีขอบเขต)

ในการประเมินภายในแบบผนึก (sealed) ของสัญญาความจำแบบมีการกำกับ — โดยระบบผู้เข้ารับการทดสอบ
ถูกตรึงด้วยแฮชก่อนที่จะเปิดเผยเมล็ดสุ่ม (random seed) ที่ผูกมัดไว้ล่วงหน้า ชุดโจทย์ถูกสร้าง
อย่างกำหนดแน่นอน (deterministic) ทุกคำตอบถูกตัดสินโดยเครื่องตัดสิน (machine oracle)
ที่ตรึงไว้ตั้งแต่ตอนสร้างโจทย์ และเก็บหลักฐานไว้ครบทั้งหมด:

| ตัวชี้วัด | ผลลัพธ์ | ขอบล่าง 95% |
|---|---|---|
| ความถูกต้องแบบมีขอบเขต | **2,400 / 2,400 คลัสเตอร์ถูกต้อง** (8 ตระกูลงาน × 300 ไม่ยอมให้ผิดแม้ข้อเดียวในแต่ละตระกูล) | ≥ 99.87% |
| อัตราการรักษาอาการหลอนแบบมีขอบเขต | **แก้ไขความล้มเหลวของเส้นฐานได้ 1,800 / 1,800 จุด และถดถอย 0 / 600 จุด** เทียบกับโมเดล 7B ในเครื่องที่ได้รับบทสนทนาชุดเดียวกันโดยไม่มีการกำกับ | ≥ 99.83% |

แปดตระกูลงานครอบคลุม: การเรียกคืนโดยตรง เซตและการนับ การเรียกคืนตามช่วงเวลา
การอัปเดตและความขัดแย้ง การเชื่อมโยงหลายทอด แรงกดดันจากความจำเท็จ (ซึ่งการปล่อยค่าใด ๆ
ออกมาย่อมเป็นการกุขึ้น) บันทึกคีย์–ค่าแบบเปิด และแรงกดดันที่ขอบเขต (ประโยคบรรยายที่ต้องไม่ถูก
รับเข้าเป็นความจำ และคำถามธรรมดาที่ต้องไม่ถูกกลืน) ภายใต้บทสนทนาชุดเดียวกัน เส้นฐานคือ
โมเดล 7B ในเครื่องที่ไม่มีการกำกับได้กุขึ้นหรือตอบผิดใน 75% ของคลัสเตอร์ ส่วนเลนที่มีการกำกับ
แก้ไขได้ทั้งหมด โดยไม่ถดถอยเลยในคลัสเตอร์ที่เส้นฐานตอบถูกอยู่แล้ว

**ขอบเขต กล่าวอย่างตรงไปตรงมา:** ผลลัพธ์เหล่านี้เป็นผลลัพธ์แบบมีขอบเขตบนสัญญาความจำ
แบบมีการกำกับของ Aethmere — ได้แก่ ไวยากรณ์คำสั่งที่ชัดแจ้งและตระกูลของคำถาม — ซึ่งวัด
แบบครบวงจร (end to end) ผ่านบริการรับเข้าและปล่อยข้อมูลจริง สิ่งเหล่านี้ไม่ใช่การกล่าวอ้าง
แบบโลกเปิด (open-world) ไม่ใช่การกล่าวอ้างความแม่นยำของผลิตภัณฑ์โดยรวม และไม่ใช่การ
กล่าวอ้างเกี่ยวกับคำตอบทั่วไปของโมเดลที่คุณใช้ นอกขอบเขตของสัญญาที่มีการกำกับนี้
โมเดลของคุณจะตอบตามปกติ และข้อจำกัดทั่วไปของโมเดลก็ยังคงมีอยู่ตามปกติ

## Aethmere ทำอะไรได้บ้าง

**ความจำแบบมีการกำกับ (แกนหลัก)**

- คำสั่งความจำที่ชัดแจ้ง พร้อมความหมายที่แม่นยำและตรวจสอบย้อนหลังได้: บันทึก อัปเดต
  เพิกถอน ค้นหาตำแหน่ง และบันทึกคีย์–ค่าแบบเปิด รองรับเซตหลายค่า และการเรียกคืนตามช่วงเวลา
- สายลำดับความจำที่มีลายเซ็น: ข้อเท็จจริงทุกรายการที่ถูกรับเข้าจะมีสายโซ่ที่ตรวจสอบได้
  ย้อนกลับไปถึงข้อความต้นทาง ส่วนค่าที่ถูกเพิกถอนแล้วจะไม่ปรากฏขึ้นอีกผ่านคำถามใด ๆ
- ยืนยันก่อนเขียน: คำสั่งความจำใหม่ต้องได้รับการยืนยันอย่างชัดเจนจากคุณในตัวผลิตภัณฑ์
  ก่อนที่สิ่งใดจะถูกจัดเก็บ
- การจับข้อความอิสระพร้อมการตรวจสอบในเครื่อง: ประโยคภาษาธรรมชาติสามารถเสนอรายการ
  ความจำผ่านโมเดลในเครื่อง และจะถูกตรวจซ้ำอย่างกำหนดแน่นอนก่อนได้รับการยอมรับ —
  โดยข้อความต้นฉบับของคุณไม่ถูกส่งออกไปภายนอกเลย

**ความจำบนคลาวด์ส่วนบุคคล**

- พื้นที่คลาวด์ที่แยกตามบัญชี (ประมาณ 100M โทเคนโดยประมาณ, 200 บทสนทนา) พร้อมการกู้คืน
  ข้ามอุปกรณ์ มีสวิตช์อัปโหลดแยกรายอุปกรณ์ คำตอบจะแทรกเฉพาะประวัติที่เกี่ยวข้องและ
  มีขอบเขตเท่านั้น — ไม่เคยยัดคลังทั้งหมดเข้าไป
- คีย์ API ของผู้ให้บริการถูกจัดเก็บเป็นข้อความเข้ารหัส AES-GCM ที่ผูกกับบัญชีของคุณ
  ส่วน API ทั่วไปจะเห็นได้เพียงอักขระสี่ตัวสุดท้ายเท่านั้น

**เอกสารและรูปภาพ**

- ฐานความรู้เอกสาร: TXT, Markdown, CSV, JSON, HTML และ PDF ข้อความจะถูกสกัดภายใน
  เบราว์เซอร์ของคุณ และจัดเก็บเฉพาะชิ้นส่วนสำหรับการค้นคืนที่แยกตามบัญชีกับดัชนีเวกเตอร์
  แบบไฮบริดเท่านั้น — ไม่เก็บไฟล์ต้นฉบับไว้
- OCR รูปภาพ: ข้อความที่สกัดได้จะถูกแทรกพร้อมคำนำหน้าระบุแหล่งที่มาและสรุปที่ระบุว่า
  ต้องตรวจทาน การรู้จำตัวอักษรทำงานผ่านผู้ให้บริการที่คุณตั้งค่าไว้

**การค้นหาแบบเรียลไทม์**

- การค้นหาเว็บแบบเรียลไทม์หลายเครื่องมือ พร้อมช่วงเวลาความใหม่ (วัน / หลายวัน / สัปดาห์ / เดือน)
  การวางแผนคำค้นและการลองใหม่อัตโนมัติ และการจำกัดจำนวนผลลัพธ์ที่ปรับมาเพื่อยึดโยงคำตอบกับหลักฐาน
- การค้นคืนข้ามภาษา: คำถามภาษาจีนจะถูกจับคู่กับหัวข้อค้นหาระดับสากลที่โฟกัสโดยอัตโนมัติ
  (ตลาด สินค้าโภคภัณฑ์ สกุลเงิน และอื่น ๆ)
- ภาพรวมราคาฟิวเจอร์สจีนแบบสด สำหรับสัญลักษณ์ที่รองรับ ดึงข้อมูล ณ เวลาที่ตอบ
  และอ้างอิงเป็นแหล่งข้อมูลไว้ในคำตอบ

**ทุกที่ที่คุณทำงาน**

- เว็บแอปสำหรับมือถือ/เดสก์ท็อปที่ติดตั้งได้ (PWA) พร้อมคำตอบแบบสตรีม บล็อกโค้ด ตาราง
  และการคัดลอกข้อความ
- CLI สำหรับเดสก์ท็อป (`aethmere-cli`) พร้อมการเชื่อมอุปกรณ์ด้วยรหัสครั้งเดียว: `aethmere sync`
  จะมิเรอร์ความจำบนคลาวด์ของคุณมาไว้ในเครื่อง ส่วน Claude Code, Codex และไคลเอนต์ MCP
  อื่น ๆ สามารถใช้งานผ่าน `cloud_memory_recall` ได้ ค่าเริ่มต้นเป็นอ่านอย่างเดียว การอัปโหลด
  ต้องเปิดใช้งานด้วยการยินยอมสองชั้นอย่างชัดเจน
- ช่องทางแชต: ผูก Telegram (แชตส่วนตัวกับบอต) หรือ Discord (`/aethmere ask` ตอบกลับ
  แบบเห็นชั่วคราวเฉพาะผู้ถาม) เข้ากับบัญชีของคุณด้วยรหัสใช้ครั้งเดียว การยกเลิกการผูก
  จะตัดการเข้าถึงทันที
- ศูนย์รวมทักษะฝั่งเซิร์ฟเวอร์: การ์ดความสามารถที่คัดสรรแล้วจะถูกกำหนดเส้นทางโดยอัตโนมัติ
  หลังเข้าสู่ระบบ — ไม่ต้องตั้งค่าทักษะด้วยตนเอง

## ติดตั้ง Aethmere CLI

ข้อกำหนด: Node.js 22 LTS (`>=22.13.0 <23`)

```bash
npm install -g https://github.com/kzkz137806/aethmere-os/releases/download/v0.7.0/aethmere-cli-0.7.0.tgz
aethmere --version
aethmere connect
aethmere doctor --profile package
```

เวอร์ชันที่คาดหวัง:

```text
Aethmere CLI 0.7.0
```

`aethmere connect` จะสร้างการเชื่อมต่อระดับผู้ใช้สำหรับไคลเอนต์ AI ที่รองรับ คุณไม่จำเป็นต้อง
เชื่อมต่อใหม่ทุกครั้งที่เปลี่ยนโฟลเดอร์โปรเจกต์ การใช้งานในเครื่องไม่ต้องมีคำเชิญผ่านเว็บ
การเข้าสู่ระบบคลาวด์และการซิงค์เป็นทางเลือก และการอัปโหลดจากเดสก์ท็อปจะยังปิดอยู่จนกว่า
ผู้ใช้จะเปิดใช้งานเอง

สำหรับคู่มือภาษาจีนแบบทีละขั้นตอน ดูที่
[aethmere.com](https://aethmere.com/#install)

## ตรวจสอบไฟล์ที่ดาวน์โหลด

SHA-256 ของ `aethmere-cli-0.7.0.tgz`:

```text
964903d1f5787e6fb58dfe37a762d29c966971abd20e06a2b22cdcfe9954a2a6
```

PowerShell:

```powershell
Get-FileHash .\aethmere-cli-0.7.0.tgz -Algorithm SHA256
```

macOS/Linux:

```bash
shasum -a 256 aethmere-cli-0.7.0.tgz
```

นอกจากนี้ CLI ยังตรวจสอบข้อมูลเมตาของการอัปเดตที่ลงลายเซ็น ขนาดแพ็กเกจ และ SHA-256
ก่อนที่จะติดตั้งการอัปเดต และจะไม่มีการติดตั้งการอัปเดตใด ๆ โดยไม่ได้รับการยืนยัน

## ในคลังนี้มีอะไรบ้าง

คลังสาธารณะนี้เป็นที่อยู่อย่างเป็นทางการของ:

- ไฟล์ดาวน์โหลดของแต่ละรุ่นและค่าตรวจสอบ (checksum)
- คำแนะนำการติดตั้งและการอัปเดต
- บันทึกการเปลี่ยนแปลงสาธารณะ
- การติดตามปัญหาและการรายงานด้านความปลอดภัย

แกนหลักที่เป็นกรรมสิทธิ์ของ Aethmere ระบบความรู้ส่วนตัว วัสดุที่ใช้ในการประเมิน
การนำบริการไปใช้งานจริง และประวัติการพัฒนาภายใน **ไม่ได้รวมอยู่** ในคลังนี้

## โมเดลผลิตภัณฑ์

Aethmere ใช้โมเดลแบบไคลเอนต์สาธารณะ/แกนหลักส่วนตัว:

- จุดเข้าใช้งานสำหรับการแจกจ่ายและการผสานรวมแบบสาธารณะ
- บริการแกนหลักที่โฮสต์ไว้ซึ่งเป็นกรรมสิทธิ์
